# homebrew-tap

Personal Homebrew tap.

## markdown-reader

This is the personal fork with runtime TOML themes and configurable,
Nerd Font-compatible status-bar separators.

```sh
brew install jskoll/tap/markdown-reader
```

If the upstream `leboiko/tap/markdown-reader` formula is already installed,
remove it before switching taps:

```sh
brew uninstall leboiko/tap/markdown-reader
brew install jskoll/tap/markdown-reader
```
